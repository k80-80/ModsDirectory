midnitetech_modlibrary

What's new?
My mods have mostly been transferred to depend on my midnitetech_modlibrary instead of multiple separate script files. As I've added more advanced scripting over time, maintaining one shared library makes updates easier and keeps my mods more reliable. If a mod you know is missing from this list, I'm probably overhauling it.

What is a script library?
A script library is a shared collection of code that multiple mods can use. Rather than every mod including the same scripting, they all reference one library, making downloads smaller, reducing duplicate files, and allowing bug fixes and new features to be updated in one place.

 TROUBLESHOOTING

Something not working properly? Check:
A. You have the latest version of the mod
B. Any dependencies are up-to-date and installed (i.e. my ModLibrary)
C. You have enabled mods/CC in-game and restarted
D. No duplicates present (outdated versions of mods can conflict with current versions)
E. Tried loading your game with JUST the problem mod and its dependencies, if applicable

 GET HELP & REPORT BUGS

Found a bug? In‑game, open the cheat console (Ctrl+Shift+C), type midnitetech.sim_report, and press Enter.

Using the file path it lists, find midnitetech_log.html and send it to me on Discord or through my Contact Form, along with your midnitetech_settings.json if the issue is related to AnyShift or Custom Uniforms.

It makes it much easier for me to troubleshoot with that, and please don't worry if you think it's a 'you' problem; I'll always help.

Command not working? If it doesn't register at all, or you get an exception/error mentioning a missing midnitetech module, then you have an outdated or incorrectly installed version of my ModLibrary. Delete it, (search your Mods folder for *modlibrary) and reinstall the latest version, linked at the top of this guide.
